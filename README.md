# 隐藏工具（HiddenTools）

一个 macOS 菜单栏小工具：让指定软件“隐身”启动——不出现在 Dock 和 Cmd+Tab，需要时还能一键隐藏窗口并把该软件单独静音。

## 功能

- 选择任意 `.app` 制作“隐藏副本”，启动后不占 Dock、不进 Cmd+Tab
- 工具本身常驻菜单栏（眼睛图标），不出现在 Dock
- 一键快速隐藏：非常快速地连按任意键两次，或按 `⌃⌥⌘H`
  - 所有隐藏软件的窗口瞬间消失，并**单独静音**；再触发一次全部恢复
- 每个软件可单独操作：显示窗口 / 隐藏窗口 / 退出 / 从列表移除
- 完全不修改原软件，不需要管理员密码

## 系统要求

- macOS 14.2 或更高（静音功能依赖系统的进程音频接口）
- Xcode 或 Command Line Tools（构建时需要）

## 构建

```bash
cd HiddenTools
./build.sh
```

产物为 `build/隐藏工具.app`，拖入“应用程序”文件夹即可使用。

## 使用

1. 打开「隐藏工具」，首次使用按提示授权：
   - 系统设置 → 隐私与安全性 → **辅助功能**（必须）
   - 系统设置 → 隐私与安全性 → **屏幕与系统音频录制**（如系统提示需要，用于静音）
   - 授权后退出并重新打开一次
2. 点菜单栏眼睛图标 → “选择要隐藏的软件…”，选择任意 `.app`（可多选）
3. 选中的软件会以隐藏副本启动：Dock、Cmd+Tab 里都看不到它
4. 快速隐藏 / 恢复：非常快速连按任意键两次，或按 `⌃⌥⌘H`
5. 菜单栏里每个软件都有子菜单：显示窗口 / 隐藏窗口 / 退出 / 从列表移除

## 注意事项

- App Store 下载的应用无法制作隐藏副本（重新签名不通过）
- 软件更新后，隐藏副本仍是旧版本，需“从列表移除”后重新选择
- 若想隐藏的软件正在运行，先退出原版，再通过本工具选择
- “连按任意键两次”在打字很快时可能误触发；如误触多，可改成双击指定键或保留组合键

## 原理

- **隐藏启动**：把原 `.app` 复制到 `~/Library/Application Support/隐藏工具/Hidden Apps`，在副本的 `Info.plist` 中加上后台应用标记并重新签名，再启动这份副本
- **窗口隐藏**：macOS 辅助功能（Accessibility）接口
- **单软件静音**：macOS 14.2+ 的 Core Audio 进程音频截获（Audio Tap），无需虚拟声卡或驱动
- **任意键双击**：CGEvent 事件截获，复用辅助功能授权

## 技术栈

原生 Swift + AppKit + Swift Package Manager，无第三方依赖。
